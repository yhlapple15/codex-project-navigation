# Codex 项目导航

为 Windows 版 Codex 增加可折叠的多级项目树。可以用虚拟文件夹整理分散在不同路径的项目，同时继续使用 Codex 自带的项目操作、聊天和活动时间线。通过独立的本地加载器运行，无需安装 Codex Tweaks。

[English quick start](README.en.md) · [版本下载](https://github.com/yhlapple15/codex-project-navigation/releases/latest) · [反馈问题](https://github.com/yhlapple15/codex-project-navigation/issues)

## 安装和启动

需要 Microsoft Store 版 ChatGPT/Codex 和 [Node.js 22 或更新版本](https://nodejs.org/en/download)。在 [Releases](https://github.com/yhlapple15/codex-project-navigation/releases/latest) 下载 **Source code (zip)**，解压后在该目录打开 PowerShell。也可以使用 Git 克隆仓库。

首次运行时先完整退出 Codex，包括系统托盘里的应用，再执行以下命令。

```powershell
npm.cmd ci
npm.cmd run build
.\Start-CodexSidebar.ps1
```

以后从项目目录运行 `.\Start-CodexSidebar.ps1` 即可启动。已通过加载器打开 Codex 时，可以用 `npm.cmd run apply` 重新加载侧栏。若侧栏未显示，请切到 Codex 模式并展开原生「项目」分区。

## 更新和卸载

- `npm.cmd run status` 查看当前窗口的加载版本
- `npm.cmd run remove` 从当前窗口撤掉增强
- 要彻底退出增强，完整退出 Codex，删除解压目录，再从 Windows 开始菜单打开 Codex
- 下载并解压新版，重新运行安装命令。使用 Git 克隆的用户可在 `main` 上运行 `git pull --ff-only`，再重新构建并加载

## 使用

- 展开项目会自动加载原生会话，首批最多 5 条。「显示更多会话」每次再显示最多 5 条。点击会话通过原生侧栏打开。
- 点击实际项目右侧的「＋」可在该项目中开始新聊天。侧栏顶部默认使用 Codex 原生的独立对话命令，不继承当前项目或它的工作路径。可在整理区关闭「顶部新聊天使用独立对话」。
- 点击「项目导航」标题右侧的「＋」新建实际项目。实际项目右侧的「⋯」打开原生项目菜单，可使用重命名等操作。
- 虚拟分组和实际项目都有独立展开箭头。一级虚拟分组用浅蓝描边文件夹，悬停或聚焦某条分支时显示虚线引导。蓝点表示原生侧栏有未读更新，折叠后仍能看到提示。
- 将鼠标移到「项目导航」标题上，点击右侧省略号打开整理选项。选择上级分组并新建子分组，再选择项目和目标分组，点击「移动项目」。
- 在整理选项里勾选「隐藏原生项目列表」可收起重复显示的项目区。原生「最近」仍可使用。取消勾选或停用功能包即可恢复。
- 打开 Codex 原生活动视图时，时间线接替「最近」的位置，项目分组保留。如果在功能包加载之前已打开活动视图，关闭后重新打开一次即可。
- 「最近按活动状态分组」仍可单独用于普通侧栏。标题旁的「原版」入口切换到 Codex 的日期时间线。
- 点击「项目导航」标题可折叠整棵树。再次展开时保留各分组的折叠状态。
- 在「管理已有分组」中选择分组，可修改名称或移除分组。改名保留组内的项目和子分组。移除时，子分组与项目会移到上一级。
- 分组、项目归属和折叠状态保存在当前 Codex 界面的本地存储中。移动项目只改变项目导航中的显示位置。

## 兼容性与权限

- 这是面向 Windows 的社区项目，使用 Codex 客户端的内部侧栏结构。官方更新可能影响项目菜单或活动视图。当前已核对 Windows 客户端包 `26.1120.5083.0` 的侧栏结构。
- 启动器为本次运行开启 DevTools 调试端口 `127.0.0.1:9335`，只绑定本机。其他本机进程可访问该端口。正常退出后从开始菜单启动 Codex，即可回到普通启动方式。应用安装文件和 Windows 安全设置无需修改。
- 此仓库同时保留旧版功能包的入口，独立启动不需要安装 Codex Tweaks。
- 读取原生侧栏已渲染的项目与会话，复用原生点击操作。无 Node 权限，无网络请求。
- 原生侧栏未加载项目时，导航会隐藏。首次试用时请让原生「项目」分区处于展开状态。
- 原生活动并排展示依赖当前 Codex 的 React 侧栏组件结构。若无法找到项目组件，活动视图按客户端原有方式打开。
- 字体继承桌面客户端设置，行高、缩进、圆角和交互颜色随侧栏界面使用的主题变量变化。

## 开发

使用 `npm.cmd run build` 构建浏览器端 JavaScript 和 CSS。修改后检查分组持久化、项目菜单与会话跳转、活动时间线和移除后的清理。官方客户端更新后，可能需要适配侧栏标记或原生菜单。

反馈问题时请附上 Windows、Codex 和项目导航的版本，以及复现步骤。截图请遮盖项目路径和聊天内容。
